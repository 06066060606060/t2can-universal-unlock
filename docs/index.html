PedalMap Control sends one immediate best-effort 0x334 one-shot from the freshest stock template when the selector changes, then remains a volatile drive-session override using the normal stock-follow overlay. Selecting STOCK releases it immediately. CHILL, SPORT and PERFORMANCE remain armed for the current drive and are cleared by a positively observed Park gear or by T-2CAN reboot. RESET FIRMWARE SETTINGS
Reset firmware settings to their defaults?
The selected vehicle profile, Wi-Fi access-point settings and stored BUS OFF evidence are preserved. S3XY devices, BLE bonds and button mappings are preserved and are not erased.

Feature settings are reset, LAB Menu returns to OFF, and Banned Car / TLSSC Restore return to OFF. BUS OFF evidence is deleted only by Reset Stats. This action cannot be undone.
