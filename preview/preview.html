bit 19 is permanently forced to 0 and bit 47 to 1 whenever the R79 gate is open. Gate sources are fresh AP ACTIVE, confirmed Summon, or fresh Park. Periodic refresh runs on its own clock and is not reset by stock mux1 RX. After one real mux1 template is captured in the current CAN epoch, the latest template is reused without a stock-age cutoff until CAN state/reinit clears it. Park is an always-on production gate source. Manual driving remains fail-closed. Bit 18 stays experimental and can be tested independently. 0x7FF remains passive RX-only.

WARNING — BANNED CAR
Enable only if this vehicle is already banned or restricted by Tesla.
This setting exposes TLSSC Restore controls. Enabling Banned Car by itself does not activate TLSSC Restore CAN transmission.
!
DANGER — TLSSC RESTORE
Enabling this option will result in the vehicle being banned.
DO NOT ENABLE unless this vehicle is already banned.

This control is intended only for vehicles that are already banned/restricted. It must not be enabled on a non-banned vehicle.
!
RESET FIRMWARE SETTINGS
Reset firmware settings to their defaults?
The selected vehicle profile and Wi-Fi access-point settings are preserved. S3XY devices, BLE bonds and button mappings are preserved and are not erased.

Feature settings are reset, LAB Menu returns to OFF, and Banned Car / TLSSC Restore return to OFF. This action cannot be undone.
!
ERASE ALL NVS
This returns T-2CAN to the first-boot vehicle selector.
The vehicle profile, firmware settings, S3XY registry and BLE bonds are erased. After reboot, T-2CAN returns to Profile Setup Mode.
